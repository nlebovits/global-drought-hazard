# Global Drought Hazard

![drought](https://img.shields.io/badge/drought-blue) ![climate hazards](https://img.shields.io/badge/climate_hazards-blue) ![hazards and risk](https://img.shields.io/badge/hazards_and_risk-blue) ![SPEI](https://img.shields.io/badge/SPEI-blue) ![extreme value analysis](https://img.shields.io/badge/extreme_value_analysis-blue) ![return period](https://img.shields.io/badge/return_period-blue)

A mirror of the [Global Drought Hazard](https://data.humdata.org/dataset/global-drought-hazard) rasters that the Institute for International Law of Peace and Armed Conflict (IFHV), Ruhr University Bochum, publishes on the Humanitarian Data Exchange. The rasters give extreme value return levels of the 6-month Standardised Precipitation Evapotranspiration Index (SPEI-6), 1902 to 2018, for five SPEI thresholds and six return periods (25 to 1000 years). The catalog holds the 30 rasters as cloud-optimized GeoTIFFs. Read [AGENTS.md](AGENTS.md) before you query.

## Processing Notes

Downloaded the 30 GeoTIFFs of the HDX dataset `global-drought-hazard` (last modified on HDX 2023-01-16) on 2026-11-20. Every file opened and read without error. Each file is about 1.8 KB smaller than the size the HDX API lists, and matches the size the HDX file store serves. Each file was rewritten as a COG with GDAL (DEFLATE, floating-point predictor, 512 px tiles, average overviews). Pixel values, the grid, and the nodata value (-3.4e38) are unchanged. GDAL 3.8 computed a NaN mean for these Float32 files, so the embedded statistics were computed with numpy over the valid pixels. The upstream files are strip-tiled (one row per block) with no overviews, so they are not read efficiently over HTTP. The build scripts are in [the repository](https://github.com/nlebovits/global-drought-hazard).
